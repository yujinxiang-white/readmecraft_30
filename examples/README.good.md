# wordcount · 极简文本字数统计

[![CI](https://github.com/OWNER/wordcount/actions/workflows/ci.yml/badge.svg)](https://github.com/OWNER/wordcount)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

> 统计一份文本的行数、字符数与中文字数，零依赖，支持管道输入。

## 目录

- [安装](#安装)
- [使用](#使用)
- [许可证](#许可证)

## 安装

```bash
pip install wordcount-demo
```

## 使用

```bash
cat article.txt | wordcount
```

输出三列：行数、字符数、中文字数。
